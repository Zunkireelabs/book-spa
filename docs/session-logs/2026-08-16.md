### 7. Real bug fixed: `getCustomerBookingHistory()` used wrong Supabase client
- `services/api.js` used the staff `supabase` client (not `supabaseCustomer`) for this customer-scoped query. In a browser with no staff session, `auth.uid()` is NULL under RLS, so booking history silently returned zero rows for real customers. Fixed to use `supabaseCustomer` — same class of bug the new membership functions were built to avoid from the start.
