## Focus: Session-Based Service Packages — Task 5 (data import)

### Actions
- Created `supabase/seed-prod-nuad-packages-import.sql`: portable, idempotent import of the 28
  customer rows from `Annual Package Details lazimpat.xlsx` (Nuad Thai Spa, Lazimpat branch) into
  the migration-141 `package_types` / `packages` tables. Resolves `org_id` (`organizations.slug =
  'nuad-thai-spa'`), `branch_id` (`branches.name = 'Lazimpat'`), and `service_id` by exact name —
  no hardcoded UUIDs. `package_types` insert is `WHERE NOT EXISTS` keyed on `(org_id, service_id,
  name)`; `packages` insert is `WHERE NOT EXISTS` keyed on `(org_id, package_type_id, guest_name,
  issued_date, sessions_total, paid_amount)` — migration-141 defines no unique constraint on
  either table beyond primary key, so these tuples are the natural idempotency keys for a re-run.
  This script is a manual dashboard/MCP handoff (not auto-applied by CI) and was **not** run
  against any live database by this task — file-only.

  Package - 120 min` (64480). `validity_days` left at schema default (365) — sheet windows are
  consistently ~365 days.
