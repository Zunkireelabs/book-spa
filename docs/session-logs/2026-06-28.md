## 2. Bottom-nav "?" placeholder bug

Root cause: `flattenNav` (`src/components/ui/StaffSidebar.jsx`) walks the
`navigationItems` tree and pushes every child object onto the flat mobile
list. The grouped children (`Operations`, `Reports`, `Staff`, `Setup`) carried
only `id / label / path / roles` — **no `icon` property** — so the mobile bar
rendered `<Icon name={undefined} />` and `AppIcon` fell back to a HelpCircle
("?"). Fix: added a Lucide icon name to every child:

| Group | Children → icons |
|---|---|
| Operations | Bookings → `BookOpen`, Calendar → `Calendar`, New Booking → `CalendarPlus` |
| Reports | Daily Report → `FileText`, Performance → `TrendingUp`, Discounts → `Percent`, Attendance Report → `CalendarCheck`, Attendance Calendar → `CalendarDays`, Transfer Report → `ArrowRightLeft`, Outstanding → `AlertCircle`, Referrals → `UserPlus` |
| Staff | Therapists/Staff → `Users`, Attendance → `Clock` |
| Setup | Rooms/Locations → `DoorOpen`, Services → `Sparkles`, Categories → `Tags`, Audit Log → `History` |

Desktop sidebar is unchanged (children still render as text-only sub-items;
the new `icon` field is just unused on that path).

## 3. Calendar view restructure (most of the session)

### Mobile sidebar (mini-cal + status legend)
Replaced the full-width left rail with a toggleable inline panel:
- Hidden by default on `<md` (`hidden md:flex`).
- A `PanelLeftOpen` button in the toolbar opens it.
- When open, it renders **inline** as a sibling of the schedule grid (pushes
  the grid right, which is now `overflow-x-auto md:overflow-hidden`, so the
  therapist columns scroll horizontally). Initially built as an overlay
  drawer; user pushed back asking for inline like desktop. Rebuilt without
  backdrop/transform/slide animation — just `hidden ↔ flex`.

### Toolbar (3 mobile rows / 1 desktop row)
Restructured via `flex flex-col sm:flex-row`:
- Row 1 (mobile only): grid `[auto_1fr_auto]` with the panel-toggle on the
  left, the centered date group (`< 28 June 2026 >`), and an equal-width
  spacer on the right to keep the date screen-centered.
- Row 2: Day / 4-Day toggle on the left, All Positions filter on the right
  (`flex-row-reverse w-full justify-between` on mobile).
- Today button + the duplicate left-side `< >` group: `hidden sm:flex` —
  redundant on mobile where the centered chevrons already nav by day.

### "Today" smart title
`formatDateTitle()` (`calendar/index.jsx:49`) now returns the literal
"Today" when the selected `dateStr` matches today's local date. Falls back
to the existing `27 June 2026` format for any other day. Applies in Day view;
4-Day range unchanged.

### Grid wrapper
`<div className="flex-1 overflow-hidden">` →
`<div className="flex-1 overflow-x-auto md:overflow-hidden">`. On mobile the
calendar grid now scrolls horizontally instead of clipping.

## 4. Floating bottom nav + New Booking FAB

Replaced the full-width bottom bar with a **floating pill** + a **chatbot-style
FAB**. Both styled to feel like Instagram's bottom nav.

### Pill nav (`StaffSidebar.jsx`)
- `fixed left-1/2 -translate-x-1/2 bottom-4 rounded-full border shadow`
- Icon + 10px label per item, stacked vertically inside the pill
- Active state: `bg-primary/10 text-primary`
- **Shrinks while scrolling**: `document.addEventListener('scroll', …, { capture: true })`
  catches scrolls from any nested scroller (including the calendar grid's own
  vertical scroll). 300ms debounce. While scrolling: labels drop, icons go
  22 → 18, padding shrinks, pill `scale-90`. Settles back when idle.

### FAB
- Separate `<Link>` to `${basePath}?view=calendar&newBooking=1`
- Circular, primary green, `CalendarPlus` icon
- `right-4 bottom-20` (above the pill), shrinks alongside the nav on scroll
- New Booking removed from the pill's primary items so the FAB owns that action

### `?newBooking=1` deep-link
`OperationalCalendar` now imports `useSearchParams` and watches for the
`newBooking=1` param. When present (and `branchId` is loaded), it triggers
`handleEmptySlotClick({ day: currentDate, colType: null, colId: null, colName: 'Unassigned' })`,
which opens the QuickCreatePanel with today + Unassigned + blank time. The
param is stripped via `setSearchParams(next, { replace: true })` so refresh /
back-nav doesn't re-trigger. `slotTime` derivation in QuickCreatePanel was
hardened with `Number.isFinite()` so an `undefined` hour/minute renders an
empty time field instead of `NaN:NaN`.

### Auto-hide floating UI while panel is open
Both the pill nav and the FAB now carry a `js-mobile-floating-ui` className.
QuickCreatePanel toggles `document.body.classList` with `mobile-panel-open`
while open. CSS rule in `src/styles/tailwind.css`:
```css
body.mobile-panel-open .js-mobile-floating-ui { display: none !important; }
```
Effect: when the QuickCreatePanel slides in, the floating chrome disappears
so it doesn't cover the Cancel / Create Booking action buttons. Restores when
the panel closes.

## 6. Top header trim (BranchSwitcher)

Symptom: on iPhone-SE width the notification bell was overlapping the right
edge of the branch dropdown. Root cause: for admin users, `BranchSwitcher`
always renders a `Platform Admin` pink pill + a `Building2` icon + the
dropdown. On mobile, that whole left section + the right section (bell +
avatar) overflowed and `justify-between` had no slack to distribute.

Fixes:
- `src/components/ui/BranchSwitcher.jsx`: Platform Admin pill and Building2
  icon → `hidden sm:inline-flex` / `hidden sm:inline`. On mobile the admin
  user just sees the dropdown.
- `src/pages/branch-manager-dashboard/index.jsx`: right section gets `ml-3`
  so the bell can never quite kiss the dropdown's edge regardless of width.

## 7. Page wrapper bottom padding

`src/pages/branch-manager-dashboard/index.jsx:417` previously had
`lg:pb-0 pb-16` (reserved space for the old full-width bottom nav). With the
new floating-pill nav, that reservation showed up as **64px of empty white at
the bottom of the calendar view** — which the user flagged as an unwanted gap.

Changed to:
```
${viewMode === 'calendar' ? 'h-screen overflow-hidden flex flex-col' : 'pb-20 lg:pb-0'}
```
- Calendar view: `pb-0`, schedule grid extends right up to the floating nav.
- Other views: `pb-20` so scrollable last items clear the nav. Desktop
  unaffected (`lg:pb-0`).
