### 3. Custom date ranges auto-switch to calendar-card view

Previously, custom ranges > 62 days triggered a "too wide for the calendar grid" error. User requested that the calendar intelligently choose the display format based on range length — 365 days → 12 cards (annually), ~180 → 6 (semi-annual), ~90 → 3 (quarterly), ~30 → 1 (monthly).

- Changed `isAggregated` from a plain const to a `useMemo`.
- Preset-mode logic unchanged (monthly/quarterly/semiannual/annually → aggregated).
- Custom-mode: counts days in the range; if > 62 → `isAggregated = true`.
- `calendarMonths` useMemo already iterates month-by-month from `range.startDate` to `range.endDate`, so it generates exactly the right number of cards for any custom range.
- `tooManyDays` is `!isAggregated && dates.length > 62`, so the error panel no longer shows for long custom ranges.

Files modified: `src/pages/attendance-calendar/index.jsx`
