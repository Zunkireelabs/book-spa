## Key Decisions
- GIST exclusion constraints for overlap prevention (not naive UNIQUE)
- Financial fields persisted on bookings (not computed at query time)
- Discount enum: `none/pending/approved` (rejection resets to `none`)
- Payment immutability: RESTRICT FK, no UPDATE/DELETE RLS
- Computed datetime fields via triggers (date + time → timestamp)
- `final_amount = base_amount - discount_amount` enforced by trigger + CHECK
